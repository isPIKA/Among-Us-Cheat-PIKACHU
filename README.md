## Installation

1. Download [**AmongPIKAMOD.zip**](https://github.com/isPIKA/Among-Us-Cheat-PIKACHU/releases/download/new/AmongPIKAMOD.zip).
2. Open the Among Us installation folder.
3. Extract all ZIP contents next to `Among Us.exe`.
4. Launch the game and wait for BepInEx to initialize.
5. Enter your License Key and press **ACTIVATE**.
6. Press **INSERT** to show or hide the menu.

Compatible with Among Us **IL2CPP x86 (32-bit)**.
